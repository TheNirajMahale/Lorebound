# Lorekeeper API Contract

This document acts as the single source of truth for the Lorekeeper backend API endpoints, models, and payloads. It was generated by inspecting the source code of the Lorekeeper Spring Boot backend.

**Base URL**: `http://localhost:8080` (or your remote API URL)
**Authentication**: All endpoints except `/auth/*` and `/open-library/*` and `/highlight` require a JWT Bearer token (`Authorization: Bearer <token>`).

---

## 1. Authentication (`/auth`)

### Register
`POST /auth/register`
**Request Body (`RegisterRequestDTO`)**:
```json
{
  "email": "user@example.com",
  "password": "securepassword123"
}
```
**Response (`AuthResponseDTO`)**:
```json
{
  "token": "eyJhbGciOiJIUzI1NiIsInR5...",
  "user": {
    "id": 1,
    "email": "user@example.com",
    "authProvider": "LOCAL",
    "createdAt": "2026-08-16T12:00:00"
  }
}
```

### Login
`POST /auth/login`
**Request Body (`LoginRequestDTO`)**:
```json
{
  "email": "user@example.com",
  "password": "securepassword123"
}
```
**Response**: `AuthResponseDTO`

### Google OAuth Login
`POST /auth/google`
**Request Body (`GoogleLoginRequestDTO`)**:
```json
{
  "idToken": "google_oauth_jwt_token_here"
}
```
**Response**: `AuthResponseDTO`

## 2. Users (`/users`)

`GET /users/me`

## 3. Private Book Library (`/books`)

### List Books
`GET /books?status={status}&query={query}`
- `status` (optional): `WANT_TO_READ`, `READING`, `COMPLETED`, `DROPPED`, `ON_HOLD`
- `query` (optional): Title/author search string
**Response**: `List<BookResponseDTO>`

### Get Book by ID
`GET /books/{id}`
**Response (`BookResponseDTO`)**:
```json
{
  "id": 1,
  "title": "Dune",
  "author": "Frank Herbert",
  "summary": "Set on the desert planet...",
  "coverImageUrl": "https://covers.openlibrary.org/b/id/12345-L.jpg",
  "format": "BOOK", // "BOOK", "COMIC", "MANGA"
  "totalPages": 896,
  "totalChapters": 48,
  "openLibraryWorkId": "/works/OL123W",
  "openLibraryEditionId": "/books/OL456M",
  "status": "READING",
  "currentPage": 120,
  "currentChapter": 5,
  "rating": 5,
  "isFavorite": true,
  "startedAt": "2026-08-15T10:00:00",
  "completedAt": null,
  "readingPosition": "epubcfi(/6/14[id12]!/4/2/2/1:0)",
  "documentId": "123e4567-e89b-12d3-a456-426614174000" // null if not uploaded
}
```

### Create Book
`POST /books`
**Request Body (`BookRequestDTO`)**:
```json
{
  "title": "Dune",
  "author": "Frank Herbert",
  "summary": "Optional summary",
  "coverImageUrl": "https://url.com/image.jpg",
  "format": "BOOK",
  "totalPages": 896,
  "totalChapters": 48,
  "openLibraryWorkId": "/works/OL123W",
  "openLibraryEditionId": "/books/OL456M",
  "status": "WANT_TO_READ",
  "currentPage": 0,
  "currentChapter": 0,
  "rating": null,
  "isFavorite": false,
  "readingPosition": null,
  "documentId": null
}
```
**Response**: `BookResponseDTO` (Status `201 Created`)

### Update Book
`PUT /books/{id}`
**Request Body (`BookRequestDTO`)**: Same as create.
**Response**: `BookResponseDTO`

### Delete Book
`DELETE /books/{id}`
**Response**: `204 No Content`

## 4. Open Library Metadata Search (`/open-library`)

### Search Works
`GET /open-library/works?title={title}`
**Response**: `List<OpenLibraryWorkDTO>`

### Get Editions for Work
`GET /open-library/works/{workId}/editions`
**Response**: `List<OpenLibraryEditionDTO>`

### Get Edition Detail
`GET /open-library/editions/{editionId}`
**Response**: `OpenLibraryEditionDTO`
```json
{
  "editionId": "/books/OL123M",
  "title": "Dune (1st Edition)",
  "publishDate": "1965",
  "numberOfPages": 896,
  "coverImageUrl": "https://covers.openlibrary.org/b/id/12345-L.jpg"
}
```

## 5. RuneGlass & Documents (`/runeglass` & `/documents`)

### Import Document (Upload EPUB/PDF)
`POST /documents/import`
**Headers**: `Content-Type: multipart/form-data`
**Body**: Form-data with key `file` (MultipartFile)
**Response (`DocumentImportResponseDTO`)**:
```json
{
  "documentId": "123e4567-e89b-12d3-a456-426614174000",
  "title": "Alice in Wonderland",
  "author": "Lewis Carroll",
  "format": "EPUB",
  "totalChapters": 12,
  "totalPages": 150,
  "chapters": [
    {
      "title": "Chapter 1",
      "contentHtml": "<h1>Chapter 1</h1><p>Down the rabbit hole...</p>"
    }
  ]
}
```

### Download Document
`GET /documents/{id}/download`
**Response**: Raw file stream (e.g., `application/epub+zip` or `application/pdf`)

### Apply Bionic Highlighting
`POST /highlight`
**Headers**: `Content-Type: text/plain`
**Body**: Raw text string
**Response**: `text/html` (HTML string with bold anchors on words)

### Dictionary Lookup
`GET /dictionary/{word}`
**Response**: `DictionaryResponseDTO[]` (Proxies Free Dictionary API format)
